# 3D 空间工作区使用手册

3D 工作区用于规划房间、机柜、设备和线路，也用于运维查线与核对资料。可在页面教程中搜索“端口”“预留长度”“U 位”等词，直接打开相应工具。

教程中的“标记已读”只记录本浏览器的阅读状态，不代表实际工程完成度。教程不会自动创建示例设备或线缆；浏览器不允许保存阅读状态时，仍可继续阅读和使用工具。

## 先分清观察与保存

| 操作 | 是否写入工程记录 |
| --- | --- |
| 查看、搜索、筛选、旋转、平移、缩放 | 否 |
| 选择 A/B 端、推荐走线、切换路线、临时测距 | 否 |
| 打开创建或编辑表单、把测距结果带入线槽表单 | 否 |
| 点击房间、机柜、设备、线槽、布线属性或出入口的保存按钮 | 是，成功后生效 |
| 点击“创建并选择”项目 | 是，创建当前工作区项目；不创建线缆 |
| 点击“确认连接并保存” | 是，创建线缆及其端口、路线记录 |

保存失败时阅读提示、调整输入后重试；表单会定位首个校验错误。取消尚未保存的表单不会提交该项修改。

房间、设备和线槽表单提供“填写建议编号”：根据当前可见同类编号建议未使用的编号，仅在名称为空时补充名称。它只填表，不保存；服务器在保存时再次检查编号冲突。

## 7 步快速上手

### 1. 选择项目与空间范围

从主导航打开“3D 空间工作区”后，先浏览建筑目录，选择楼层或房间，再点击“进入楼层3D”或“进入房间3D”。选择卡片和搜索结果只改变待进入的位置，不会立即打开场景。保存的上次范围可作为已选项，仍需点击进入。

建筑和园区只用来选择位置，不把多个楼层合并展示。进入楼层后只加载本层及其房间；进入房间后只加载该房间范围。直接挂在建筑下、尚未归属楼层的房间单列保留，不会擅自移动到某一层。已选楼层／房间的直达链接可在权限核验后直接恢复。

场景顶部显示已知层级路径，点击“切换楼层 / 房间”返回目录；若有接线草稿、未保存表单或临时测距，会先确认是否放弃。目录底部保留“创建房间”，空工作区也可先建立第一个房间，再进入。

左侧“对象列表”只筛选本次进入范围内的房间和资产。多房间并排是同一范围内的示意布局，不代表实测距离。跨层线路只显示当前场景可见部分，并提示还有场景外登记路径；不补画其他楼层，也不把部分路径小计当成全程长度。

单击物件查看详情；双击列表中的机柜进入机柜视图。机柜模式下，按 `F` 或点击“适配全部对象”直接放大到当前机柜。通过“空间总览”返回房间布局。

对象标签会自动避让；缩远时只显示部分标签，选中对象优先。右上角图层设置按当前浏览器的账号和工作区保留；关闭对象标签不会关闭线路 / 测距长度。

### 2. 建立房间与出入口

1. 选择房间工具，填写编号、名称、房间类型及宽、深、高，单位为米。
2. 检查尺寸后点击“保存房间”。新房间默认在南墙居中创建一个入口。
3. 选中房间，在对象详情中点击“配置出入口”。设置所在墙面、洞口起始边距、净宽与净高，再点击“保存出入口”。

南、北墙的边距沿房间 X 轴计算；东、西墙沿 Y 轴计算。边距从该墙坐标较小的一端量至洞口起点。每间房至少保留一个入口。

### 3. 批量布置机柜

选择机柜工具，在房间地面点击落点；也可使用“填写参数”。设置数量、列数、机柜间距、旋转和尺寸，确认后保存。

- 一次可建立 1–12 个机柜，列数为 1–6；批量编号和名称自动追加 `-01`、`-02` 等序号。
- 位置 X/Y 以机柜中心为准，单位米；宽、深单位为毫米，高度单位为 U。
- 保存时检查房间边界、净高及与现有机柜的重叠。若失败，调整位置或间距后再保存。
- 已有机柜可在对象详情中点击“调整位置”，确认后保存。

### 4. 安装设备并确认介质策略

选择服务器、交换机、铜配线架或光纤配线架工具，点击目标机柜；也可在安装表单选择设备模板与机柜。

核对编号、名称、起始 U 位及前后安装面后，点击“保存设备”。点击落点时会尝试填写附近连续空闲 U 位；若没有足够空间，需换机柜或调整安装面。设备端口随模板生成。

表单中的“采用空闲 U 位”按当前机柜、模板高度及安装面选择最小连续空闲位置，跳过已占用及预留 U 位。没有足够位置或设备资料不完整时会提示原因，并保留原值。切换机柜或模板后可再次点击建议按钮；保存时仍会重新校验。

选中设备或线槽，可在“布线属性”设置：

- 是否允许布放线缆。
- 允许铜缆、光纤，或两者。

点击“保存布线属性”才会生效。属性是规划与使用约束，不会证明现场已经按该规则施工。端口已占用、状态不可用或介质不符合策略时，不可选择为新连接的端点。

### 5. 选择 A/B 端并确认走线

打开接线工作区后，在“保存到项目”选择布线项目。没有项目时，具备创建权限的成员可点击“新建项目”，填写编号和名称，再“创建并选择”。已有端口选择、线缆编号及预留长度会保留；创建项目不会自动保存线缆。唯一活跃项目会自动选中；若工作范围已限定项目，直接使用该项目。

1. 选择铜缆或光纤工具。当前可选择 Cat6A、Cat6 铜缆以及 OS2、OM4 光纤。
2. 点击机柜或设备，依次选择空闲、兼容的 A/B 端口。也可直接拖接端口，或在接线工作区按机柜、设备、端口名称搜索。
3. 两端有效后，系统推荐走线。查看经过的线槽与路径段，可换方案、排除线槽或手动增删、排序路径段。
4. 手动改动后点击“校验当前走线”。清空路径段表示不经过已记录线槽的直连，仍需校验；不会把断开的线槽自动视为连续路线。
5. 填写线缆编号与“预留长度（m）”，核对“将保存的登记长度”，最后点击“确认连接并保存”。

**登记长度 = 当前路线估算 + 预留长度。** 切换方案后按新路线重新计算，预留不会重复累加。路线估算采用实际经过的线槽部分，加上端口接入距离估算。端口可从线槽中途接入、离开；候选中显示“使用 / 全段”长度和沿线槽坐标的接入、离开位置。局部长度按几何占比折算整段登记值；段登记长度无效时采用段坐标长度。登记值不是自动产生的现场实测值。

保存后高亮和“长度与路径段”保留同一使用范围；线路追踪和 CSV 导出也使用局部长度。既有未记录接入位置的线路仍保留整段路由。预览后线槽坐标或登记长度改变时须重新计算再保存；已保存线路遇到此变化会要求重新核对，不再沿旧范围补画或导出有效长度。

若保存时提示端口被占用，先刷新场景再选择可用接口。仅选择端口、查看推荐或调整预览不会创建线缆。

### 6. 测距并转为线槽

选择“测距”，在同一房间内依次点击地面或物件表面，最多保留 64 个点。测距面板在左侧，不遮挡画布；切换至对象列表仍可查看测距结果。

| 数值 | 含义 |
| --- | --- |
| 图示总长 | 每一段三维直线距离之和 |
| 水平投影距离 | 每一段在房间地面上的投影距离之和 |
| 累计高差 | 每一段升降高度的绝对值之和，下降也计入 |

不足两点时尚未形成测量。同一终点附近的重复点击会被忽略；不同房间之间不能直接测量。

- “撤回一点”移除最后一个测点，“清空”移除全部测点。
- “完成测距”停止取点并保留临时结果；“继续取点”接着测量。
- 切换其他工具或按 Esc 会清除临时测距。测距不会自动保存。
- “用于创建线槽”把折线转换为房间本地坐标，带入线槽表单。X/Y 为平面坐标，Z 为高度，单位米。逐点核对位置和高度后点击“保存线槽”。

测点可以在后续线槽参数表单中修改。也可直接选择线槽工具，在表单中添加、删除坐标点。打开或取消表单不会保存线槽。

### 7. 查线并核对长度来源

在对象列表搜索线缆，或从设备、机柜的“关联线缆”进入详情。核对 A/B 端设备与端口、经过的线槽和路径段。

**端口连接示意不表示已经记录实际走线路径。** 已记录线槽坐标的线路会沿该路径展示；端口到线槽的接入部分仍可能是示意。

“长度与路径段”分别显示登记线缆长度、路径段登记长度及坐标长度，并提示当前已加载多少段。登记值可能来自估算、人工录入或包含预留；坐标长度来自当前模型。两者有差异时，需要核对记录与现场情况，不能仅以图形长度覆盖登记值。

“检查当前场景”核对当前已加载数据中的入口资料、摆位、长度与路由资料，以及既有线缆的策略冲突。按问题入口查看或修复。检查不覆盖未加载数据，不代表全网健康，也不承诺所有问题都能自动修复。

## 工作助手：规划与运维

左侧“工作助手”提供“规划安装”和“日常运维”两组任务。规划步骤按房间、机柜、设备、线槽、连接排序；显示的数量是当前范围已记录对象数，不是工程完成率。缺少前置房间或机柜时会引导先创建。

自动检查随场景数据更新运行，分为“待核对”和“资料提示”。可按对象名称或编号搜索，点击对应入口查看详情；房间入口、机柜位置和布线属性可通过现有表单处理。其他条目只提供查看入口，尚未支持完整编辑。打开工作助手或从教程进入检查／对象列表会保留当前接线草稿和临时测距；返回工具箱可继续。接线中先保存或退出接线，才能定位处理检查项。页面刷新或离开后的草稿恢复尚未提供。刷新失败时会标记资料过期，待刷新成功再继续操作。

## 视角与快捷键

先点击画布，使其获得键盘焦点。输入框中的按键不会移动视角。

| 操作 | 效果 |
| --- | --- |
| 拖动空白处 | 旋转视角 |
| 右键拖动，或选择“平移”后左键拖动 | 平移视角 |
| 滚轮、`+`、`-` | 缩放 |
| `W` / `A` / `S` / `D` | 水平移动视角 |
| `Shift` + 移动键 | 加速移动 |
| `F` | 适配全部对象 |
| `1` / `2` / `3` | 正面 / 背面 / 俯视 |
| `Esc` | 退出当前工具并清除临时测距；在教程内仅关闭教程 |

也可使用画面上的等轴、正面、背面、俯视及缩放按钮。“设置三维图层”可控制机柜外壳、对象标签、线槽 / 桥架及“线路 / 测距长度”的显示。

## 规划记录与未来发现数据

Observium 目前尚未接入。未来发现设备或逻辑邻接关系，不等于已经确认物理端口对接、跳线、光纤芯路或线槽经过顺序。发现信息只能作为核对线索，物理连接仍需结合现场核验后登记。

规划时先把尺寸、摆位、端口和路径资料补齐；运维时先确认查看范围，再查端点、路径段及长度来源。保存记录与现场核验各有用途，不应互相替代。

## 删除与拆除已保存线缆

在对象列表中选中线缆，右侧详情提供“删除规划线缆”或“拆除线缆”；线缆台账也有入口。先核对预览中的编号、端点、路径及阻碍，再确认。拆除必须填写原因。成功后端口可重新连接，历史与审计保留；没有一键恢复。

有未完成工单或已登记纤芯／铜缆线对拓扑时不自动级联删除，无权限时显示原因。冲突或失败后，先“刷新影响预览”再核对。编辑、接线或临时测距未结束时，先完成或退出当前操作。完整规则见 [线缆维护说明](CABLE_MAINTENANCE.md)。
