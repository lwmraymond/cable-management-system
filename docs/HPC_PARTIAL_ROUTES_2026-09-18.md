日期：2026-09-18。分支：`codex/local-build`。本地部署：`127.0.0.1:18000`。

## 问题与结果

旧线路只保存“经过哪一整段线槽”，两端即使位于桥架中途，也需要遍历整段再绕回设备。本轮新增首末段接入、离开位置，沿原始三维折线累计距离；预览、保存和刷新后的高亮使用同一局部范围。

| 流程 | 当前行为 |
| --- | --- |
| 自动推荐 | 端口向首末线槽投影，保留中间完整路径段、拐弯、竖向与反向走线；仍仅在登记端点连接不同段 |
| 候选与长度 | 显示“使用 / 全段”、接入与离开位置；线槽部分按几何比例折算登记长度，接入估算和预留分别列出 |
| 持久化 | 路由行保存 `start_offset_m`、`end_offset_m`、`geometry_hash`，接线接口及通用线缆创建接口均验证 |
| 3D | 待确认橙色实线；保存后选中蓝色高亮；未经过的线槽仍保留原本完整外形 |
| 追踪与导出 | 线路追踪返回裁剪后的坐标与采用长度；CSV Route Length 采用局部长度，Design Length 保留线缆登记值 |
| 源几何改变 | 预览后变更拒绝保存并要求重算；已存范围标记失效，停止补画旧范围和输出有效路由总长度 |
| 旧数据 | 未记录接入范围的旧路线继续保持整段语义；不改写已存在光纤 |

## 当前边界与后续

接入长度仍是直线估算，图中端口到线槽的接入折线用于示意；局部登记长度不等于现场测量。几何指纹针对线槽坐标及有效整段长度，不是整个机房或端口姿态的版本快照。

搜索仍有规模与候选数上限，采用最近合规线槽和登记端点拓扑，不保证全局最短，不自动打通交叉线槽中点，不包含避障或跨房间／楼层路由。此次仅验证两条光纤，没有布置完整 fabric，也没有验证光模块、breakout、电力和散热设计。
