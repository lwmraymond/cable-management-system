## 安装与升级

依赖安装、生产构建和启动命令见 [本地开发指南](LOCAL_DEVELOPMENT.md)。已有本地环境可执行：

```bash
.venv/bin/python scripts/local-dev.py build
.venv/bin/python scripts/local-dev.py start
```

迁移 head 为 `200000000012`。升级已有数据库前应创建一致性备份。迁移 012 保留旧整段路线，为新线路增加局部范围；存在局部路由记录时拒绝有损降级。回退旧应用需要对应的升级前数据库备份，期间新增数据需另行处置。

Git 版本包含源代码、测试、迁移、依赖锁文件和文档。本机 `.local/` 数据库、HPC 验证数据、备份、日志及构建产物继续留在本地；新环境启动默认导入 Northstar 演示数据，不会自动得到本机的 240 柜场景。停止本地服务不会删除数据。

## 边界

本版本是经过本地验证的开发版本。LDAP、Observium 等外部连接器、批量装配满柜、跨房间／楼层自动路由、全 fabric 布线与生产并发验证尚未完成。线槽路由是有界候选搜索，不保证全局最短或避障；长度仍为规划估算。真实 PostgreSQL RLS、真实身份提供方及外部系统仍需在对应环境验证。
