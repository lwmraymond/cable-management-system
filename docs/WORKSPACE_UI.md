# 工作台与位置页面改进

2026-09-17，本地 `codex/local-build` 分支。范围：`/app-next` 首页、`/app-next/locations` 和公共导航／工作范围设置。

## 页面结构

- 导航分为工作空间、基础设施、光纤工程；中文名称与当前页高亮一致。旧版入口移至导航底部。
- 顶部用单行显示页面位置与当前工作位置名称。中等窗口默认收起导航，可手动展开；小于 768px 使用抽屉导航。
- 首页显示四个主要资产指标、规划和运维入口、工作／测试计数及真实近期工单。只链接已经存在的页面，不生成假趋势、健康率或活动。
- 位置列表将名称与编号组合展示，补充上级位置、中文类型、搜索／类型筛选、已加载和筛后数量。原空白状态列移除；未知上级不虚构名称。
- 表格在窄窗口内部滚动，3D 操作固定在右侧。楼层／房间行进入对应场景；园区、楼宇等行进入位置目录，再明确选择楼层或房间，不混合不同楼层。保留租户、用户和项目，服务端继续校验访问权限。
- 工作范围设置优先按名称选择位置；租户／项目 UUID 等放入高级设置。取消不会应用，重开恢复当前值，省略的可选字段也不会残留草稿。

## 统计含义

当前 `/dashboard` 是租户汇总，不随项目或位置选择缩小。页面显式说明这一点，不能拿它与某一个 3D 房间的数量直接比较。

| 后端字段 | 当前页面名称与解释 |
| --- | --- |
| buildings | 建筑数量 |
| telecom_rooms | 通信间；仅 TR、MDF、ER、MMR，不含数据机房 |
| racks / devices | 已登记机柜／设备，包括未摆位／未入柜记录 |
| active_cables | 未拆除线缆；包括规划、库存、安装与在用等状态，不表示全部在线 |
| open_work_orders | 未结工单；不含已完成与已取消 |
| failed_tests | 累计失败测试记录，不是尚未处理的告警数量 |
| expiring_access | 实现实际统计 ACTIVE 授权，页面显示“有效授权”，不能称为即将到期 |

缺失、非法数值与真实的 0 分开显示。刷新失败不将旧统计呈现为最新数据，并提供重试入口。

## 请求与范围切换

`useApiResource` 向 loader 提供可选 AbortSignal，保留原零参数 loader 用法。只有最新请求能更新数据、错误与 loading；卸载时中止请求。即使旧 loader 不响应取消，迟到响应也不能覆盖新范围。

同范围刷新可保留最近成功的数据；依赖变化的首轮渲染即隐藏旧数据与错误。公共业务页面在租户、用户、项目或位置变化时重新挂载，清除旧范围选中对象与表单状态。

## 验证

- 全部前端：250 项通过（30 个测试文件），本轮新增 32 项覆盖首页数据含义、失败恢复、位置筛选／导航、请求竞争、范围切换和表单取消。
- TypeScript 与 Vite 正式构建通过；原有大包提示仍存在，主应用约 585kB gzip，3D 工作区单独加载约 210kB gzip。
- 浏览器覆盖 1440px、默认 862px、375px：首页布局、移动导航、位置搜索、固定行操作、工作范围表单，以及位置进入 Server Room 后显示 4 机柜／16 设备。
- 375px 页面本身宽度保持 375px，位置表格仅内部滚动。临时 viewport 覆盖在验收后恢复。
- 本轮只修改前端与说明文档，没有后端 API、数据库或业务记录变更。

## 边界

机柜、线缆、光纤等页面保留现有功能，只继承公共导航与主题；尚未逐页完成内容布局与术语整理。工单卡显示已返回记录，尚无新版工单详情页。统计范围及字段含义需要在后续后端产品化中进一步统一。
