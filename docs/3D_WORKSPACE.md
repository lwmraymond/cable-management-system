## 线槽中途接入与局部路由（2026-09-18）

- 新线路将 A/B 端口投影到首末线槽折线，中间路径仍只连接登记端点（1 mm 容差）。记录从源折线起点累计的 `start_offset_m`、`end_offset_m`，允许反向；完整保留折弯及高度。
- 候选、橙色预览、保存后的蓝色高亮、长度明细、线路追踪与 CSV 均使用同一局部范围。采用长度 = 整段登记长度 × 使用坐标长度 / 整段坐标长度；登记无效时用坐标长度。接入直线估算和预留另计，接入绘图仍为示意。
- `POST /scene/routes/preview` 返回 `route_portions`；`POST /scene/cables` 和 `POST /cables` 均重新验证完整有序范围、同房间、端点接缝及 `geometry_hash`。坐标或有效长度变化返回 409；无效范围返回 422。预览不会占用端口。
- `/scene` 的已保存范围带 `valid`。线槽变化后不补画过期局部线路；长度明细提示核对，追踪返回无有效长度／坐标，CSV 路由总长度留空并注明原因。既有总登记长度保留供核对。
- 新增迁移 `200000000012`，原线路三列为空，继续保持原来的整段语义，不自动重算旧线路。存在任何局部路由记录时拒绝有损降级；恢复旧版本需同时恢复升级前数据库备份。
- 路由仍是有界候选搜索，不承诺全局最短、避障、跨房间／楼层自动走线，线槽交叉也不会自动生成中途接缝。验收记录见 [局部路由验收](HPC_PARTIAL_ROUTES_2026-09-18.md)。

## 240 柜场景修复（2026-09-18）

- 接线工作区可选择或创建当前工作区的布线项目，保留正在编辑的端口、编号和预留长度；缺少项目时提前禁用保存。唯一活跃项目自动选择。项目创建按成员权限校验，并记录审计。
- `/scene` 首批最多返回 10,000 个端口，并给出 `port_page.total/next_cursor`；后续通过 `GET /api/v1/scene/ports?after=<uuid>&limit=<1..10000>` 获取。每页重验账号、项目与位置范围。前端完整收齐后发布场景，遇到缺页、重复页、范围或数量变化则报错，不把分页残缺当作完整数据。
- 线缆发现与端点完整性使用全部授权端口，因此首批之外的线缆端点不会丢失。其他资源上限仍保留；前端只清除已解决的 `ports` 截断提示，最多收集 100,000 个端口。
- 总览不生成细小的交互端口模型。机柜检查与接线模式恢复端口细节和双端拾取，保留跨柜拖线。全部端口资料仍用于容量、搜索和连线校验。
- 对象标签按屏幕空间避让、避开边缘和长度标注，优先显示选中对象，限制远景标签密度。图层偏好按浏览器中的工作区和账号保存；长度标注有独立开关。
- 机柜模式下“适配全部对象”、`F` 和视角切换按机柜包围盒取景，不再被房间地板拉远。
- `GET /api/v1/projects` 返回当前授权项目目录及 `can_create`；`POST /api/v1/projects` 接受 `project_number/name`。仅具备 `cable:create` 的工作区成员可创建，客户组织由工作区确定，外部承包方不可创建工作区项目。

实测结果、测试命令和仍未解决的限制见 [HPC 修复验收](HPC_REPAIRS_2026-09-18.md)。上述首批修复不新增数据库迁移；后续局部路由使用迁移 `200000000012`。

## 建筑目录与独立楼层（2026-09-18）

- `/app-next/3d` 先读取授权位置目录；选择建筑、楼层或房间后，明确点击“进入楼层3D”或“进入房间3D”。目录阶段不预载完整场景，WebGL 工作区按需加载。
- 建筑／园区仅作为目录。`?browse=<id>` 浏览目录，`?location=<floor-or-room-id>` 恢复明确选定的场景；旧 `?room=<id>` 链接保留。仅有 `?cable=` 或 `?rack=` 的旧链接先选择范围，再定位对象。机柜台账链接有位置 ID 时直接携带该位置。
- 位置台账的建筑／园区行打开目录，楼层／房间行直接进入该范围。账号、租户和项目保持；场景请求前同步已选择位置并继续执行服务端授权。
- 楼层和实际房间的递归查询不会穿透其他 floor/building，即使旧数据存在异常嵌套关系。未归属楼层、直接挂在建筑下的房间独立列出，不迁移或虚构父级。缺失的上级只显示“未加载”，不补造层级。
- 场景顶部提供层级路径与“切换楼层 / 房间”；该按钮返回目录，不再直接把工作范围扩大到整栋建筑。未保存的接线／表单／临时测距需明确放弃后切换；其他页面离开行为仍按原有规则。
- 目录保留创建房间入口，包括空工作区首个房间。创建成功刷新目录并选中实际保存的房间，由用户确认进入；没有新增建筑／楼层批量创建能力。
- 跨层线缆只返回本地端点及路径。新增 `route_scope=none|complete|partial` 表示登记路径引用覆盖情况；`partial` 不补造接入或直连，也不误报完整路径断开。长度只显示本次加载的小计。`complete` 不保证坐标完整或连续，仍检查坐标及截断。
- 原有 `/scene` 无范围／建筑聚合读法为既有接口保留兼容；新网页入口不使用它来绘制多层场景。此更新不改变记录父级、ID 或数据库结构。

## 创建与操作

右上角“新建”提供五种操作，均通过 API 保存到数据库，成功后重新读取场景；失败保留表单内容。

1. **房间 / Server Room**：编号、名称、上级位置、宽/深/净高；普通房间映射 `room`，服务器机房映射 `data_hall`。空房间也能查看并继续布置。
2. **批量放置机柜**：一次 1–12 台、每行数量、起始中心 X/Y、净间距、宽深、U 高、朝向。编号自动添加 `-01` 等序号；全部成功才保存，任一冲突整批回滚。
3. **安装设备**：选择机柜、模板、起始 U 位和前/后侧。模板自动生成端口，检查规格、已占用及预留 U 位。选中机柜后安装会默认该机柜。
4. **线槽 / 桥架**：编号、名称、类型，以及按顺序添加/删除的 X/Y/高度点；自动计算三维折线长度。场景内显示线槽结构与编号标记。
5. **线缆连接**：打开接线工作区，选择介质和 A/B 空闲端口，自动推荐连续线槽路线。切换候选、排除线槽或手动调整段顺序后校验，最后点击“确认连接并保存”。预览不写入或占用端口；保存再次校验策略、连续性与物理占用。

选中机柜后，“调整位置”可保存 X/Y、底部高度和朝向。保存带版本校验，检查完整旋转包围区域、房间边界和机柜碰撞。机柜高度含顶框 `U × 0.04445 + 0.1925m`；新建最小宽 500mm、深 450mm。旧窄规格以渲染器实际最小外形检查，但不改写原始尺寸。

“房间 / 机柜 / 线槽 / 线缆”列表支持搜索。选中线槽可查看槽内线缆，选中线缆可查看端口并跳转设备。选择其他房间对象会同步 UI 范围；创建新对象后同步直达链接。切换楼层／房间通过位置目录重新选择，仍由服务器检查权限。

## 工具箱、拖放安装、端口布线与出入口

- 左侧“工具箱”采用类似 Packet Tracer 的点击工具模式，分为选择/平移、连线、设备和空间。选中工具高亮，画布顶部显示下一步操作；机柜/线槽工具在地面单击定位，设备工具在目标机柜上单击安装，均先填写参数再确认保存。房间工具直接打开尺寸及类型表单；“填写参数”提供无需三维拾取的入口。
- 保留铜缆、光纤、线槽、机柜、配线架、交换机、服务器和房间拖放。地面落点填入局部 X/Y，机柜落点填入机柜和附近空闲 U 位；楼层直属资产空间也保留正确名称和 ID。线槽起点距同房间已有端点 0.4m 内时吸附完整 XYZ。超过 6px 的拖动只旋转视图，不误触放置；平移工具改为左键平移，Esc 或选择工具退出当前工具。
- 内置标准硬件模板可直接安装，模板在首次保存时创建；仍检查连续空闲 U 位、预留和设备尺寸。
- 选择铜缆 / 光纤后，**点击机柜或设备 → 从可用接口列表选 A 端 → 点击对端并选 B 端**，自动计算路线；接口可按设备名、编号和连接器筛选。也可左键按住空闲三维端口拖至对端。右侧搜索下拉框与场景选择保持 A/B 同步；手动更改端口或介质会关闭旧接口弹窗。Escape 退出接线并清除预览。
- 绿色端口可用、灰色端口占用或被设备策略禁用；草稿路线为橙色实线，确认后的选中线缆为亮蓝色。自动推荐依据合规线槽的连接图与估算长度，最多 3 个候选，不声称全局最短。接缝容差前后端均为 1mm；仅连接已记录段端点，不自动连接相交线槽中点。
- 设备 / 线槽详情增加“允许布放线缆”和“允许的介质（铜缆 / 光纤）”。这些是保存的属性，预览与写入都检查；关闭后不会删除既有线缆。策略更新使用版本校验。
- 新房间默认南墙居中入口。在房间详情点“配置出入口”可新增、调整墙面、洞口起始边距、净宽和净高；至少一个入口，拒绝越界或重叠。南北墙 offset 从最小 X 起算，东西墙从最小 Y 起算。3D 显示墙洞、门框、开启示意和名称；原有未配置的房间明确提示，不生成虚构入口。

## 工作助手、自动检查与教学

- 左侧增加“工作助手”，在规划安装与日常运维之间切换。规划步骤以房间→机柜→设备→线槽→连接组织；任务数量仅表示已加载记录，缺少前置对象时引导先创建。
- 每次场景资料更新后只读检查 8 类问题：出入口、尺寸、机柜摆位与边界、设备入柜资料、路由缺录、长度缺录、路径资料连续性与完整性、既有线缆的介质策略冲突。按对象名称／编号搜索、按级别筛选并分批展示。明确当前范围、截断资料和刷新失败，不把隐藏资料或直连跳线误判为断线。
- 检查项可定位对象并打开已有的入口、机柜位置或布线属性编辑；其他项只查看详情。检查不自动修复或保存。浏览工作助手、教程检查和对象列表会保留接线草稿与临时测距；接线中需先保存或退出，才能定位处理检查项。刷新或离页后的草稿恢复尚未提供。
- 常驻“使用指南”包含 7 步可搜索教程、快捷键与工具入口；阅读状态按当前浏览器、租户和用户保存，存储受限时仍可使用，不代表工程进度。正文见 [3D 使用手册](USER_GUIDE_3D.md)。
- 房间、设备、线槽可显式填入建议编号，保留已填写的名称；设备可选择最小连续空闲 U 区间，考虑安装面、模板高度与预留。设备列表截断或没有足够空位时提示，保存仍做最终校验。表单提交失败定位首个校验错误。
- 修正机柜视图切换后的相机聚焦、页面级 Escape 的组合键与输入法保护、触屏平移模式；首次加载失败显示重试，不显示无效的空房间创建入口。
- Observium 等连接器尚未接入；已整理来源发现、匹配预览、确认绑定、字段归属和同步历史的 [产品路线与连接器设计](PRODUCT_ROADMAP_AND_CONNECTORS.md)。

## 三维显示

- 机柜框架、导轨、U 位、设备机身与独立可选端口；低墙、底板、门框与名称；线槽底板、侧沿、横档与标记。
- 标签关闭深度测试并覆盖渲染，不遮挡鼠标拾取。缩放时维持约 10–12px 字号；标签不参与相机取景边界。
- **线缆常驻实线显示**，普通线为蓝灰色，选中线加粗并提高亮度；重合路径优先显示选中线。点击模型或列表均可选择。
- 已记录路径按原始坐标分段显示。全部路径段连续且双端完整可见时，增加设备端口到线槽的接入示意，详情明确说明接入段的性质。
- 完全未绑定路线的双端连接以实线表达端口关系，不代表实测路线。部分端点、缺失/无效/断开的登记段不会被擅自补成完整线路。
- 鼠标左键旋转、右键平移、滚轮缩放。点击画布或用 Tab 聚焦后，按住 `W/S` 沿当前观察方向在水平面前进/后退，`A/D` 左右横移，`Space` 上升、`Shift` 下降；相机朝向保持不变，斜向移动速度一致。松键、失焦、切到其他应用/标签页后立即停止，表单、弹窗、放置/接线/测距模式及组合快捷键不会触发移动。
- 画布聚焦时 `F` 适配、`1/2/3` 前/后/俯视、`+/-` 缩放。键盘移动只在按住移动键时请求动画帧；速度随查看尺度调整，无碰撞或重力模拟。工具栏保留等轴视角与相机控制。
- 支持单机柜查看、设备近景、房间/线槽/完整连接定位；外壳、标签、线槽图层可切换，线缆保持显示。

源数据位置单位为米、尺寸为毫米、旋转为度、Z 向上；前端转换为 Three.js Y 向上和弧度。多房间按分区示意排列，不推断楼宇绝对变换与房间之间实测距离。缺失尺寸或无效/重叠坐标会提示采用示意范围/摆位，渲染不会修改数据库。

## 线路长度与折线测距

- 选中线缆 / 线槽后，右侧显示登记线缆长度、当前已加载路径段的登记长度与坐标长度、逐段明细和差异。登记值可以来自估算或人工录入，不称为实测值；空值显示“—”。缺段、重复、断开、无效或截断的数据不会被拼成完整总长；多空间只显示单段小计，不推断空间间距离。场景 API 的路径引用受当前可见范围限制，因此小计不代表完整敷设线路。
- 三维图中，选中线路的可信路径段显示坐标长度；预览段为橙色。尺寸标签位于普通对象标签上层，独立于“对象标签”开关，通过“线路 / 测距长度”统一开关。示意接入段及跨空间示意不标物理长度。
- 左侧工具箱新增“测距”：依次点击同一房间的地板或模型表面，生成临时实线折线、测点和分段 / 总长标签。面板显示三维总长、水平投影距离、累计高差与房间内 X/Y/Z 坐标；可撤回、清空、完成后继续取点，最多 64 点。拖动仍控制相机，不误采点；Esc、切换工具或切换空间清除测距。长度按当前模型坐标计算，不能作为现场测量值。
- “用于创建线槽”将测距点转换为该房间局部坐标并打开线槽表单；可以逐点修改 X/Y、离地高度或增删坐标点，再确认保存。点击地板的高度为 0，需要架空线槽时应在表单设置实际高度。测距和转换本身不写数据库，取消表单不创建对象。
- 接线工作区增加长度配置，分列线槽采用长度、端口接入 / 直连估算、路线估算及额外预留。保存长度为当前候选估算加预留，精确到 0.001m；切换候选不会重复累加。预留只计入最终 `length_m`，不单独持久化。自动路线采用有效的路径段登记值，否则回退坐标长度；端口接入按距离估算，不应以渲染器的接入示意折线反推登记长度。

## API 与权限

读取 `GET /api/v1/scene`；编辑入口：

| 方法 | 相对 `/api/v1/scene` 路径 | 用途 |
| --- | --- | --- |
| POST | `/rooms` | 创建房间 |
| POST | `/racks` | 原子批量放置机柜 |
| PATCH | `/racks/{id}` | 带 `expected_version` 保存位置 |
| POST | `/devices` | 模板设备与端口 |
| POST | `/pathways` | 线槽及坐标段 |
| POST | `/cables` | 物理端接与路径引用 |
| POST | `/routes/preview` | 只读路线推荐或自定义路线校验 |
| PATCH | `/devices/{id}/cable-policy` | 布线准入与介质策略 |
| PATCH | `/pathways/{id}/cable-policy` | 线槽准入与介质策略 |
| PATCH | `/rooms/{id}/entrances` | 保存房间出入口 |

所有引用必须在租户、项目、位置与用户权限范围内，非成员按目标范围重新解析授权。端口返回 `occupied` 布尔值，隐藏对端不泄露身份。新接口拒绝非有限坐标、越界、碰撞、占用、版本及标识符冲突；失败回滚审计与数据。读取有数量限制并返回 `truncated` 提示。新增迁移 `200000000009`，为 Pathway 增加 JSON `cable_policy`；设备策略使用 `instance_overrides.cable_policy`，入口使用 `Location.dimensions.entrances`。升级前本地 SQLite 已备份至 `.local/app-before-installation-009.db`。`local-dev.py start` 自动运行迁移。
